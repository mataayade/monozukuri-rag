# 段6b 根拠ページのずれの修正

## 不具合
回答末尾の「根拠: p.308」を AI が自分で書くため、実際に使った断片のページとずれた。
例: マイスター・ハイスクール(t07)は、定義文が p.118 の断片なのに p.308 と書いた(修正前、qwen3:14b・k=8 で再現)。

## 直し方
- 断片に [1]〜[8] の番号を振り、AI には使った断片の番号だけを [1][3] の形で答えさせる(ページ番号は見せない)。
- src/answer.py の attach_evidence が番号を抜き出し、断片 → 紙面ページに変換して「根拠: p.118」を付ける。番号が無い・範囲外は「根拠ページ不明」。「資料には書かれていません」の時は付けない。
- src/app.py は使われた断片を根拠欄の先頭に出す。src/evaluate.py は使われた断片(used_idx, cited_pdf_pages)を記録する。
- 1 回目はプロンプトの文言が悪く、AI が「根拠に使った【資料】の断片の番号」と文を書き写した(正解 19/40)。文言を「最後の行に、使った断片の番号だけを書く」に直して再実行したのが下の結果。

## 結果(qwen3:14b、k=8、40 問、判定は段 4 と同じ glm)

| 項目 | 修正前(段4 改善c k=8) | 修正後(段6b) |
|---|---|---|
| 正解 | 24/40 (60%) | 24/40 (60%) |
| 部分正解 / 不正解 / でっち上げ | 9 / 6 / 1 | 10 / 6 / 0 |
| 回答が挙げた根拠ページが正解ページを含む率(absent 除く 32 問) | 26/32 (81%) | 23/32 (72%) |
| 根拠ページ不明の件数 | 0 | 0 |
| t07 の根拠 | p.308(定義文は p.118) | p.118 |
| 秒/問 | 9.9 | 8.6 |

- 正解率は同じ。
- 根拠が正解ページを含む率は下がった。修正前の 26/32 は AI が全断片の中から選んだ値で、修正後は番号で選んだ断片のページだけを数えるため。ずれ(例 t07)は解消したが、番号選びが上手でない問がある(検索が当たっていても別の断片の番号を挙げる)。
- 修正前の根拠ページは「p.N の N + 13 = PDF ページ」で換算して集計した。
- 判定は揺れる(1 回目の実行は同じ設計で 19/40 → 文言修正後 24/40)ので、正解率の差は 1〜2 問では言い切れない。
